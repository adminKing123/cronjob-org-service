Cron Service API

Register Fuse workflow schedules with cron-job.org. Incoming pings hit GET /webhook/<workflow_id>, then this service POSTs to noney-api.

Auth: Authorization: Bearer <SERVICE_API_KEY> on management routes.
Public callback: cron-job.org calls GET {PUBLIC_HOST}/webhook/{workflow_id} (no auth).

Upsert schedule

POST /api/schedules/upsert

FieldRequiredDescription
workflow_idYesFuse workflow ID
workflow_nameNoDisplay name
owner_idNoFirebase UID
owner_emailNoFailure notification recipient
schedule_configYesSchedule starter node config (incl. schedule_mode, timezone, etc.)
cron_expressionNoIgnored — computed from schedule_config for logs/admin
timezoneNoIANA timezone (defaults from schedule_config)
noney_trigger_urlYesnoney-api POST URL to run the workflow
noney_trigger_secretYesBearer token for that URL

Delete schedule

DELETE /api/schedules/<workflow_id>

Example — upsert

curl -X POST "$PUBLIC_HOST/api/schedules/upsert" \
  -H "Authorization: Bearer $SERVICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "workflow_id": "abc123",
    "workflow_name": "Daily report",
    "owner_email": "user@example.com",
    "schedule_config": { "schedule_mode": "daily", "hour": "9", "minute": "0", "timezone": "UTC" },
    "cron_expression": "0 9 * * *",
    "noney_trigger_url": "https://noney.example/fuse/schedule/webhook/abc123",
    "noney_trigger_secret": "secret-from-noney"
  }'
